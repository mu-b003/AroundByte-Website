AROUNDBYTE MAIN WEBSITE — FIXED PACKAGE
=======================================

IMPORTANT: Extract the ZIP contents directly into the document root of aroundbyte.com.
The archive is intentionally arranged so index.html is at the ZIP root, with assets/ beside it.

Expected document root:
  index.html
  products.html
  about.html
  contact.html
  privacy-policy.html
  cookie-policy.html
  terms.html
  disclaimer.html
  assets/

All HTML pages share assets/style.css, assets/site.js, assets/aroundbyte-logo.png,
and assets/favicon.svg. Navigation and footer links connect the pages.

Local test:
  python3 -m http.server 8080
Then open http://localhost:8080/
